## Что делает `scripts.js`

По коду видно, что параметры из `offerUrl` разбираются:

```js
function getOfferUrlParams() {
    const offerUrlValue =
        offerUrl instanceof URL
            ? offerUrl.toString()
            : String(offerUrl || '');

    const [, queryString = ''] = offerUrlValue.split('?');

    if (!queryString) {
        return [];
    }

    return queryString
        .split('&')
        .filter(Boolean)
        .map(item => item.split('='));
}
```

Затем они добавляются в форму как скрытые поля:

```js
function syncOfferParamsToForm(form) {
    const params = getOfferUrlParams();

    params.forEach(([name, value]) => {
        upsertHiddenField(form, name, value);
    });
}
```

Перед отправкой происходит:

```js
syncOfferParamsToForm(form);
event.target.submit();
```

Также в форму добавляется или обновляется:

```text
sub_id_15
```

Нужно показать на конкретном примере, что будет, если:

```js

    'https://example.com/offer'
    + '?subid=CLICK-123'
    + '&campaign_id=92';
```

# Почему меня спросили «получали готовый или писали сами»

Мне нужно понять все возможные значения этого вопроса.

## Вариант 1. Готовый postback URL

Например, Keitaro или партнёрка дают готовую схему:

```text
https://tracker.example.com/postback
?subid={click_id}
&status={status}
&payout={sum}
```

Интегратор:

- вставляет URL в кабинет партнёрки;
- подбирает макросы;
- проверяет тестовую конверсию.

## Вариант 2. URL собирают вручную

Интегратор читает документацию и сам сопоставляет:

```text
click_id партнёрки → subid Keitaro
state партнёрки → status Keitaro
commission партнёрки → payout Keitaro
```

Но отдельную программу при этом может не писать.

## Вариант 3. Готовый серверный файл

Например:

```text
postback.php
```

который уже умеет принять параметры и переслать их в Keitaro.

Интегратор меняет:

- домен;
- API-токен;
- имена параметров;
- соответствие статусов.

## Вариант 4. Самостоятельный обработчик

Разработчик сам пишет серверный код, который:

1. принимает запрос от партнёрки;
2. получает `click_id`;

4. проверяет параметры;
5. переводит статусы партнёрки в статусы Keitaro;
6. собирает запрос;
7. отправляет его в Keitaro;
8. логирует ответ и ошибки.

Нужно объяснить, какой из этих вариантов HR, скорее всего, имел в виду.

# Пример предполагаемого самостоятельного обработчика

Это только учебная гипотеза. Проверь и исправь.

```php
<?php

// Параметры, которые прислала партнёрская сеть
$clickId = $_GET['click_id'] ?? '';
$partnerStatus = $_GET['state'] ?? '';
$payout = $_GET['commission'] ?? '0';

if ($clickId === '') {
    http_response_code(400);
    exit('Missing click_id');
}

// Переводим статусы партнёрки в статусы трекера
$statusMap = [
    'lead' => 'lead',
    'sale' => 'approved',
    'reject' => 'rejected',
];

$keitaroStatus = $statusMap[$partnerStatus] ?? 'lead';

$keitaroPostbackUrl =
    'https://tracker.example.com/postback?'
    . http_build_query([
        'subid' => $clickId,
        'status' => $keitaroStatus,
        'payout' => $payout,
    ]);

$curl = curl_init();

curl_setopt_array($curl, [
    CURLOPT_URL => $keitaroPostbackUrl,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 10,
]);

$response = curl_exec($curl);
$error = curl_error($curl);
$httpCode = curl_getinfo($curl, CURLINFO_HTTP_CODE);

curl_close($curl);

if ($response === false) {
    http_response_code(502);
    exit('Keitaro request failed: ' . $error);
}

header('Content-Type: application/json; charset=utf-8');

echo json_encode([
    'success' => true,
    'keitaro_http_code' => $httpCode,
    'keitaro_response' => $response,
]);
```

Нужно объяснить каждую часть простым языком.

Также нужно отдельно объяснить:

- сам файл не является «магическим postback»;
- postback — это запрос;
- файл может быть отправителем, получателем или промежуточным обработчиком запроса.

1. Не начинай со сложной терминологии.
2. Используй одного конкретного пользователя и один click ID.
3. На каждом шаге говори:
   - кто выполняет действие;
   - где выполняется код;
   - куда идёт запрос;
   - что передаётся;
   - кто хранит результат.
4. Не смешивай:
   - browser JavaScript;
   - server PHP;
   - настройки Keitaro;
   - CRM;
   - кабинет партнёрки.
5. Пиши код целиком, без `...` и пропусков.
6. Комментируй код на русском.
7. Не утверждай то, чего нельзя установить по файлам.
8. При необходимости попроси меня показать:
   - настройки кампании Keitaro;

   - Network-запрос формы;
